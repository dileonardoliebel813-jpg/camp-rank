# CampRank 外包数据采集具体任务单

## 当前状态：本文档旧版多平台任务已暂停

从当前项目继续导入剩余数据时，只采集和整理京东帐篷商品、京东评论、京东价格、京东售后服务和京东商品链接。淘宝/天猫、小红书、拼多多、什么值得买相关任务暂不执行，不能把这些平台的数据补进当前推荐链条。

当前真正执行的流程以这两份文档为准：

```text
docs/next_agent_data_pipeline_handoff.md
docs/camprank_data_to_frontend_pipeline.md
```

如需给数据服务方新的任务单，本次只要求京东表格字段：SKU、pid、评论内容、评论得分、评论时间、追评、追评时间、当前价格、商品链接、售后服务、店铺名称、商家回复、图片数量、得分类型。所有数据必须真实可追溯；拿不到就写 warning，不允许编造。

本文档给数据服务方执行使用，说明本次到底需要找哪些平台、哪些商品、哪些关键词、哪些数据文件。字段格式和验收标准见 `docs/data_vendor_requirements.md`，字段必须以 `docs/camprank_required_data_contract.md` 为准。

重要：数据不是越多越好，而是必须能导入 CampRank。请先阅读 `docs/camprank_required_data_contract.md`，确认能按 `canonical_products / platform_products / product_specs / product_prices / product_benefits / return_policies / comments / redbook_notes` 八类交付。

## 1. 总目标

注意：本节以下“淘宝/天猫、小红书”相关内容是旧版多平台任务。当前继续导入剩余数据时不执行；当前总目标只覆盖京东帐篷商品、京东评论、京东价格、京东售后服务、京东店铺名称和京东商品链接。

围绕“户外帐篷”这个品类，完整收集京东、淘宝/天猫、小红书的公开可访问或授权可获取数据，用于 CampRank 的商品比较、评论分析、售后风险分析和推荐评分。

本次不是只做几个样例，而是要做完整数据包。但仍需先交付一个小试验包确认格式，确认后再批量交付。

## 2. 平台范围

必须覆盖：

- 京东：商品、价格、参数、售后、公开评价摘要。
- 淘宝/天猫：商品、价格、参数、售后、公开评价摘要或公开评价概览。
- 小红书：帐篷相关公开口碑摘要、使用体验、避坑内容。

可选补充：

- 什么值得买：帐篷优惠、历史好价、用户讨论摘要。
- 拼多多：价格补充和低价平台对比。

第一版优先完成京东、淘宝/天猫、小红书。

## 3. 目标商品品类

只收集“帐篷”相关商品，优先以下类型：

- 双人帐篷。
- 三人帐篷。
- 四人及以上家庭帐篷。
- 徒步轻量帐篷。
- 公园露营帐篷。
- 自动帐篷 / 速开帐篷。
- 防雨帐篷。
- 四季帐 / 高山帐。
- 隧道帐。
- 金字塔帐。
- 充气帐篷。

不要采集以下非目标商品，除非商品明确是帐篷套装的一部分：

- 单独天幕。
- 睡袋。
- 防潮垫。
- 折叠椅。
- 营地车。
- 炉具。
- 单独地钉、风绳、帐杆配件。
- 二手商品。
- 明显不是户外帐篷的儿童玩具帐篷。

## 6. 数量要求

完整交付建议数量：

京东：

- 不少于 50 个真实帐篷 SKU。
- 每个 SKU 尽量提供 20-100 条公开评价摘要。
- 每个 SKU 尽量提供商品基础信息、参数、价格、优惠、售后。

淘宝/天猫：

- 不少于 50 个真实帐篷商品。
- 尽量覆盖淘宝店和天猫店。
- 每个商品尽量提供商品基础信息、参数、价格、优惠、售后、公开评价摘要或评价概览。

- 优先真实使用体验、测评、避坑、漏水、搭建、收纳、空间、防雨、售后相关内容。

每个平台如果实际公开可访问数据不足，请说明原因，并在 warnings 中写清楚。

## 7. 京东具体任务

京东需要交付两类文件。

### 7.1 京东商品完整数据

文件建议：

```text
jd_tents_products_full.json
```

每个 SKU 需要尽量包含：

- SKU ID。
- 商品标题。
- 品牌。
- 型号。
- 商品链接。
- 主图。
- 店铺名称。
- 店铺类型。
- 是否自营。
- 当前价格。
- 原价。
- 优惠券。
- 运费。
- 销量或评价数。
- 好评率。
- 防水指数。
- 重量。
- 展开尺寸。
- 收纳尺寸。
- 杆材。
- 面料。
- 帐篷类型。
- 搭建方式。
- 售后规则。
- 退货条件。

### 7.2 京东公开评价摘要

文件建议：

```text
jd_comments_full.json
```

也可以按 SKU 拆分：

```text
jd_comments_<sku_id>.json
```

每条评价需要：

- SKU ID。
- 评价正文。
- 评分。
- 评价时间。
- 是否带图。
- 是否追评。
- 追评内容。
- 公开可见规格标签。
- 商家回复。
- 非隐私原始字段。

不要包含用户昵称、头像、用户 ID、IP、详细地区等个人隐私字段。

## 9. 小红书具体任务

文件建议：

```text
redbook_tents_notes_full.json
```

每条笔记摘要需要：

- 公开笔记链接。
- 标题。
- 正文摘要。
- 公开评论摘要。
- 点赞数。
- 收藏数。
- 评论数。
- 关联品牌。
- 关联型号。
- 涉及风险标签。
- 数据来源说明。

优先收集以下内容：

- 真实露营体验。
- 帐篷测评。
- 帐篷避坑。
- 漏水反馈。
- 防雨表现。
- 搭建难度。
- 收纳难度。
- 空间大小。
- 异味。
- 售后退货体验。
- 新手帐篷推荐。

小红书只作为口碑补充，不作为价格和商品参数权威来源。

## 10. 风险和差评重点

评论和口碑摘要中，请特别保留以下风险相关内容，方便 CampRank 做有效差评识别：

- 漏水。
- 冷凝水严重。
- 杆子断裂。
- 拉链坏。
- 布料开线。
- 地钉质量差。
- 结构不稳。
- 风中倒塌。
- 空间偏小。
- 人数虚标。
- 防水指数虚标。
- 尺寸不符。
- 重量偏重。
- 收纳体积过大。
- 味道大。
- 防晒差。
- 搭建困难。
- 退货麻烦。
- 退款慢。
- 退货运费争议。
- 客服态度差。

这些内容不要被过滤掉，即使是差评，也非常重要。

## 11. 商品选择规则

请选择有代表性的商品，不要只选销量最高或价格最低的商品。

京东和淘宝/天猫商品池建议覆盖：

- 低价入门款：100-300 元。
- 中端主流款：300-800 元。
- 高端款：800 元以上。
- 双人款。
- 家庭多人款。
- 徒步轻量款。
- 自动速开款。
- 防雨性能主打款。
- 大空间露营款。

每个平台尽量覆盖多个品牌、多个价位、多个使用场景。

## 13. 试验包要求

正式批量交付前，请先交付一个试验包，用于验证导入。

试验包内容：

- 京东 3 个真实 SKU。
- 每个 SKU 10 条左右公开评价摘要。
- 淘宝/天猫 3 个真实商品。
- 小红书 5 条公开口碑摘要。
- 一个 `warnings` 汇总。

试验包通过后，再按完整数量交付。

试验包不是最终规模，只是为了避免格式不一致导致批量返工。

## 14. 最重要的交付原则

数据服务方需要交付的是“可导入、可追溯、可分析”的结构化数据。

请不要只交付截图、网页 HTML、未整理文本或字段混乱的表格。

如果字段拿不到，可以缺失；如果访问受限，可以停止；但不能编造字段，不能混入个人隐私数据。
