# CampRank 项目总体设计

## 1. 项目背景

户外露营消费在年轻用户中快速增长，但帐篷是一个参数密集、风险后置、平台差异明显的商品。新手用户经常只看销量、低价或宣传图购买，收到后才发现漏水、断杆、异味、空间偏小、防晒差、退货麻烦等问题。

CampRank 的目标不是简单抓取商品列表，而是把多平台信息转化成可解释的消费决策。系统需要理解商品本身是否值得买，也需要理解同一款商品在哪个平台购买更稳妥。

## 2. 目标用户

- 18-28 岁大学生。
- 刚上班、预算敏感但希望降低踩坑概率的用户。
- 轻露营新手，例如公园露营、周末短途、第一次过夜露营用户。
- 对平台优惠、退货保障和真实口碑没有经验的用户。

## 3. 用户核心痛点

- 不会看帐篷参数：防水指数、杆材、面料、尺寸、收纳体积、重量等参数难以理解。
- 平台信息分散：京东、淘宝/天猫、拼多多、什么值得买、小红书的信息口径不同。
- 商家宣传容易夸大：空间、适用人数、防水、防晒、赠品价值等容易被包装。
- 评论真假混杂：模板化好评、返现好评、低信息好评会拉高表面评分。
- 差评不一定都有效：快递慢、颜色不喜欢和漏水、断杆的决策价值不同。
- 最低价平台不一定最划算：低价可能伴随抢券、复杂凑单、无运费险、退款慢或售后差。
- 退货和售后风险难判断：帐篷问题常在展开或使用后发现，退货政策决定实际损失。

## 4. 系统总目标

用户输入预算、人数、使用场景和偏好后，系统输出：

- Top 推荐帐篷。
- 推荐购买平台。
- 最低价平台。
- 平台差价。
- 优惠和赠品对比。
- 退货风险。
- 评论风险。
- 小红书口碑。
- 避坑理由。

推荐结果必须包含解释，不允许只给一个排名或一个总分。用户应该能看懂为什么这款帐篷适合自己，为什么这个平台更稳妥，为什么某个平台虽然便宜但不推荐。

## 5. 系统八层架构

### 5.1 数据采集层

负责从京东、淘宝/天猫、拼多多、什么值得买、小红书等来源获取商品、价格、优惠、评论、退货政策和口碑数据。第一版可使用 mock/sample 数据跑通流程，真实采集后续采用可插拔模块。

采集层只负责获取原始信息，不直接决定推荐结果。

### 5.2 数据标准化层

把不同平台的字段统一成标准字段，例如价格、尺寸、重量、防水指数、赠品、退货保障、评论来源、更新时间等。标准化层需要保留原始字段和标准字段，方便追溯。

### 5.3 同款识别层

通过品牌标准化、型号关键词、标题相似度、关键参数相似度和主图相似度占位，把不同平台的同一标准商品归并。未完成同款识别前，不允许直接跨平台比价。

### 5.4 评论质量控制层

对评论进行低信息过滤、疑似刷评识别、真实体验识别、有效差评分类和可信度加权。评论不默认真实，只有经过可信度加权后的评论才进入风险和评分计算。

### 5.5 商品能力评分层

评估帐篷本身能力，包括防水、防风、空间、便携、搭建、耐用度等。商品能力评分以标准商品为对象，不绑定某一个平台。

### 5.6 价格优惠与退货比较层

在同一标准商品下比较不同平台的稳妥到手价、理论最低价、优惠稳定性、赠品保守价值、退货保障、退款风险、售后信誉和店铺可信度。

### 5.7 场景化推荐层

根据用户场景调整权重，例如新手公园露营更重视搭建便利和退货风险，徒步轻量更重视重量和收纳体积，家庭多人露营更重视空间和稳定性。

### 5.8 前端解释展示层

展示 Top 推荐、平台推荐、最低价平台、差价、优惠、赠品、风险标签、避坑理由和数据置信度。前端不能只展示分数，必须展示推荐理由和风险说明。

## 6. 推荐流程

第一步：先比较标准商品，判断哪款帐篷值得买。

- 对原始商品进行字段标准化。
- 进行同款识别，得到标准商品。
- 汇总各平台评论和口碑。
- 计算商品能力分、评论风险、数据置信度。
- 输出标准商品级别的 Top 推荐。

第二步：再比较同一标准商品在不同平台的价格、优惠、赠品、退货和售后，判断在哪个平台买。

- 计算 StableFinalPrice 和 TheoreticalLowestPrice。
- 计算 CouponReliabilityScore。
- 计算赠品保守估值和 GiftAdjustedCost。
- 计算 ReturnProtectionScore、ReturnRiskScore 和 RiskAdjustedCost。
- 输出 lowest_price_platform 和 recommended_platform。

## 7. 核心边界

- 爬虫只是数据采集层，不是系统核心。
- 同款识别失败时，不进行直接价格比较。
- 评论未经过可信度处理时，不进入核心评分。
- 最低价只是一项信息，不是最终推荐结论。
- 数据缺失时可以推荐，但必须降低置信度并说明缺失项。
